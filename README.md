# SAT Practice — sat9

Тренажёр SAT с сохранённым интерфейсом, 10 вариантами, адаптивными модулями и серверным прогрессом.

## Учебные функции

- 30 уроков на русском, узбекском и английском: покрыты все 29 тем каталога, плюс отдельный урок согласования.
- Каждый урок: объяснение, правила, разобранный пример, типичные ошибки, авторская мини-практика с пояснением.
- Экзамен с таймером и тренировка без ограничения времени. Перевод в активном экзамене запрещён сервером.
- Вопросы и исходные объяснения остаются на английском. Кнопка машинного перевода использует Workers AI; оригинал всегда доступен. Формулы и рисунки следует сверять с оригиналом.
- Разбор → урок → похожие официальные задания → повторение через 1/3/7/14 дней.
- Кэш оригинальных вопросов в D1 переживает перезапуски. При временной недоступности источника используется ранее загруженная копия до 30 дней; ещё не загруженные вопросы требуют доступности источника.
- Восстановление по одноразовому личному коду, отзыв старых сеансов после смены пароля. Создай код в разделе «Безопасность» и сохрани отдельно.
- Подтверждение email и восстановление по письму: после настройки почтового сервиса.

## Запуск и проверки

Node.js 24:

```sh
npm ci
npm test
npm run dev
```

`npm test` проверяет синтаксис, собирает Worker и выполняет модульные, серверные и Cloudflare/D1 тесты с искусственными заданиями. Тестовые данные не используются в production.

Публикация и настройки внешних сервисов: [CLOUDFLARE_SETUP.md](CLOUDFLARE_SETUP.md).
Состояние проверки: [VALIDATION.md](VALIDATION.md).

Код оплаты и текущие цены сохранены. Новые платёжные реквизиты не подключены.
